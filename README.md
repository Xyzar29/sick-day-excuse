## What it does

`main.ts` writes a single line — one original, funny sick-day excuse — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is under 200 characters, a single
line, and nothing else.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Requires Node 22 or later.
